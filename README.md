# Ghost Ink

A typing test that turns your unique typing rhythm into a signed digital signature.

Built with vanilla HTML, CSS, and JavaScript — no frameworks, no backend.

## Why
Typing tests measure speed. Ghost Ink measures identity — the timing
patterns between your keystrokes, turned into a unique cryptographic key
via the Web Crypto API, visualized as a generative "signature".

## Status
🚧 In progress — building in public.

## Run it
Just open `index.html` in a browser. No build step, no install.
